ALL ON YOUR DEVICE

Browser learning engine

Zero chat or training backend. The website directly requests public Wikipedia articles through Wikimedia's Action API, stores data and model checkpoints in IndexedDB, and trains a small causal Transformer using local Web Workers.

Compute: Self-contained JavaScript CPU engine. WebGPU acceleration is not yet implemented. The website works on static hosting such as GitHub Pages.

Limitations: This starts with random weights, so early local responses can be nonsense. Broad knowledge takes far more compute than a phone can provide. Training progress and declining loss do not establish general reasoning skill.

Background: The learning loop operates while this page is open and the browser permits execution. Closing the tab stops computation; reopening can resume from IndexedDB. Mobile browsers may suspend background tabs.
